# 每日画布（Daily Canvas）

每日画布是一款重视隐私、以本地保存为默认方式的个人规划与习惯追踪工具。它把主线领域、固定计划、浮动任务、每周或每月配额目标、习惯、每日小记和可编辑历史放在同一个响应式界面中。

## 0.6 版：习惯生命周期与奖励

- 达到阶段目标后先进行克制的庆祝，再选择继续、转为维持、延长目标、完成或归档。
- 支持预先计划的休息、假期和事后补填暂停；暂停日期既不算完成，也不算失败。
- 预先计划的暂停会冻结当前连续记录；累计完成、历史最佳和过往里程碑永久保留。
- 事后补填暂停不能修复暂停创建前已经发生的遗漏。
- 中断恢复会如实显示当前连续记录结束，同时提供继续原计划、调整计划或暂停。
- 固定习惯和配额目标都有生命周期状态、里程碑时间线和就近奖励领取。
- Dexie 数据库和备份格式升级到 v5，并迁移所有旧版本数据。

## 0.5 版：日历与人性化回顾

- 可按本周、上周、本月、上月或任意有效的自定义日期区间进行包含首尾日期的回顾。
- 用英文或中文阅读以“实际完成了什么”为核心的平静事实摘要，不提供行动建议。
- 可按来源日期核对重复任务完成记录，并分别查看固定计划、浮动任务和配额目标。
- 可查看领域分布、计划类型分布、已结束配额周期，以及可选的回顾、情绪和体验背景。
- 日历支持汇总、单任务、单领域模式，并可按任务类型、计划类型和记录类型筛选。
- 日历使用标签、形状、数量和完整图例，不只依赖颜色；支持键盘导航和日期证据详情。
- 可在本地复制易读的回顾文本，不会上传数据。

## 0.4 版：回顾与个性化

- 每日回顾从多选情绪开始，再进入不限制篇幅的完整自由书写空间。
- 支持自定义情绪标签、重复归一化、归档复用；用户文字不会被自动翻译。
- 温和的双语提示使用本地持久化洗牌袋，当前一轮用完前不会重复，也可跳过或关闭。
- 打卡后可选择记录轻量体验；体验记录与打卡结果相互独立，空白不会被保存为负面数据。
- App、Today、Calendar 和 Reflection 可分别使用仅保存在本地的背景图片，并调整填充、位置、遮罩和模糊。
- Dexie 数据库与备份格式升级到 v4；旧日记全文和原有应用背景会安全迁移。

## 0.3 版：灵活规划与主线领域

- 新增可编辑的主线领域，支持名称、颜色、图标、排序、归档和安全删除。
- 任务可以关联一个领域并继承其颜色，也可以使用任务自己的颜色覆盖。
- 新增独立的浮动任务列表；未选择的日期保持中立，逾期也不会变成习惯失败。
- 新增每周和每月配额目标，以周期完成次数判断达标，并按成功周期计算连续记录。
- Today、Tasks、Calendar、历史和统计会区分固定、浮动和配额三类语义。
- 数据库升级到 Dexie v3，备份格式升级到 v3，并兼容迁移受支持的旧数据。

## 0.2 版：可信赖的每日核心

- 数据库与备份格式都有明确版本和迁移流程，旧数据可安全升级。
- 导入前会验证并显示恢复摘要；确认恢复前自动下载当前数据的安全备份。
- 增加启动失败恢复、错误边界、可见保存状态和可操作的错误提示。
- 增加首次使用引导、可编辑示例、清晰空状态和两步式任务创建。
- 月历遵循星期一或星期日作为每周起始日的设置。
- 自动化关键流程覆盖启动、新建、打卡、历史补录、备份恢复和语言切换。

## 基础功能

- 新建、编辑、归档、恢复、星标、分类和删除任务。
- 区分普通任务、好习惯和戒除习惯，并使用不同的打卡语义。
- 支持每天、指定星期、每隔 N 天循环，以及可选结束日期。
- 支持 7、21、30、66、90 天或自定义阶段目标。
- 使用鼠标、触控或键盘拖拽调整当天任务顺序。
- 使用彩色月历总览和单任务热力图查看历史。
- 补录过去的日期，区分完成、安全日、失守、跳过和未记录。
- 统计当前连续、历史最佳和完成率。
- 每天可以写一篇不超过 500 字的小记。
- 按指定日期或连续天数设置奖励。
- 中文和英文界面、浅色和深色主题、减少动态效果。
- 使用只保存在本地的自定义背景图片。
- 导出和恢复 JSON 数据备份。

## 隐私模式

每日画布目前没有账号、分析统计、广告、云端数据库或远程字体依赖。任务、打卡、日记、奖励和自定义背景默认保存在当前设备、当前浏览器来源的 IndexedDB 中。

浏览器数据可能被浏览器清理，因此建议定期导出 JSON 备份。未来如果增加跨设备同步，应当由用户主动开启，而不是悄悄改变本地优先的隐私模式。

请勿向 Git 仓库提交真实的个人备份、含真实数据的截图、`.env`、数据库、日志或凭据。项目的 `.gitignore` 已拦截常见的本地专用文件。

## 本地开发

需要 Node.js 20.19 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

验证命令：

```bash
pnpm typecheck
pnpm test
pnpm build
```

## 架构原则

项目使用 React、TypeScript、Vite、Dexie/IndexedDB、i18next、date-fns 和 dnd kit。任务定义与每天的打卡记录分开保存；循环任务根据日期规则计算，不会无限复制出每日任务副本。

详细数据模型和扩展边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 状态含义

- 好习惯或普通任务：完成、跳过、未记录。
- 戒除习惯：明确确认的安全日、失守、跳过、未记录。
- 没有打卡绝不会被自动算成戒除成功。
- 跳过不会增加连续天数，也不会打断连续记录；同时不计入完成率分母。
